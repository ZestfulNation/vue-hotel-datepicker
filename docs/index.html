A date range picker for Vue 3 that counts nights, enforces stay rules and speaks six languages.

Install

Requires Vue 3. Vue 2 projects should stay on vue-hotel-datepicker@4.

npm install vue-hotel-datepicker
import HotelDatePicker from 'vue-hotel-datepicker'
import 'vue-hotel-datepicker/dist/vueHotelDatepicker.css'

export default {
  components: { HotelDatePicker },
}
<HotelDatePicker :modelValue="true" />

Period dates

Give date ranges their own minimum stay, period type or price. Weekly periods only allow check-out on their weekday, and their minimumDuration is counted in weeks.

KeyTypeDescription
startAtStringYYYY-MM-DD.
endAtStringYYYY-MM-DD.
minimumDurationNumberMinimum stay. Counted in nights for nightly and in weeks for the weekly types.
periodTypeStringnightly, weekly_by_saturday or weekly_by_sunday.
priceNumberPrice shown on each day of the period.
periodDates: [
  {
    startAt: '2020-06-09',
    endAt: '2020-07-26',
    minimumDuration: 4,
    periodType: 'nightly',
  },
  {
    startAt: '2020-07-26',
    endAt: '2020-09-30',
    minimumDuration: 1,
    periodType: 'weekly_by_saturday',
  },
  {
    startAt: '2020-09-30',
    endAt: '2020-11-30',
    minimumDuration: 2,
    periodType: 'weekly_by_sunday',
    price: 4000.0,
  },
]

Turn on “Period dates” in the sandbox

Bookings

Draws existing bookings on the calendar. Clicking one emits booking-clicked.

KeyTypeDescription
checkInDateStringYYYY-MM-DD.
checkOutDateStringYYYY-MM-DD.
styleObjectInline style for the booking marker, such as backgroundColor.
bookings: [
  {
    event: true,
    checkInDate: '2020-08-26',
    checkOutDate: '2020-08-29',
    style: { backgroundColor: '#399694' },
  },
  {
    event: false,
    checkInDate: '2020-07-01',
    checkOutDate: '2020-07-08',
    style: { backgroundColor: '#9DC1C9' },
  },
]

Events

NamePayloadDescription
booking-clickedMouseEvent, Date, ObjectA booking was clicked. Receives the mouse event, the clicked date and the booking.
check-in-changedDateA new check-in date was selected.
check-out-changedDateA new check-out date was selected.
clear-selection—The clear button was clicked.
day-clickedDate, String, Date | Number | StringA day was clicked. Receives the date, its formatted string and the next disabled date.
handle-checkin-checkout-half-dayObjectEmitted before mount, on clear and on check-out. Receives an object with the check-in and check-out dates.
next-month-rendered—The next month was rendered.
period-selectedEvent, Date, DateA check-out was clicked. Receives the mouse event, the check-in and the check-out.

Methods

To open or close the picker from your own button, set closeDatepickerOnClickOutside to false and call these methods through a template ref.

NameDescription
showDatepickerShows the datepicker.
hideDatepickerHides the datepicker.
toggleDatepickerShows the datepicker if hidden, hides it if shown.

Translations

Pass an object to i18n. Bundled locales in this repo: Portuguese, French, English, Spanish (Spain and Latin America) and Italian. These are the English defaults: 

i18n: {
  night: 'Night',
  nights: 'Nights',
  week: 'week',
  weeks: 'weeks',
  'day-names': ['Sun', 'Mon', 'Tue', 'Wed', 'Thur', 'Fri', 'Sat'],
  'check-in': 'Check-in',
  'check-out': 'Check-out',
  'month-names': [
    'January', 'February', 'March', 'April', 'May', 'June',
    'July', 'August', 'September', 'October', 'November', 'December',
  ],
  tooltip: {
    halfDayCheckIn: 'Available CheckIn',
    halfDayCheckOut: 'Available CheckOut',
    saturdayToSaturday: 'Only Saturday to Saturday',
    sundayToSunday: 'Only Sunday to Sunday',
    minimumRequiredPeriod: '%{minNightInPeriod} %{night} minimum.',
  },
}
